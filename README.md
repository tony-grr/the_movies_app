# The Movies App

## Описание проекта
The Movies App — это Android-приложение, предназначенное для просмотра каталогов фильмов, получения подробной информации о конкретных фильмах и управления синхронизируемым списком избранного. Проект представляет собой практическую реализацию современных стандартов Android-разработки с использованием реактивной модели программирования и строгого разделения ответственности.

## Архитектура
Приложение следует принципам Clean Architecture в сочетании с паттернами представления MVVM и MVI. Кодовая база разделена на три основных слоя:
* Слой предметной области (Domain Layer): Содержит основную бизнес-логику, сущности и определения вариантов использования (use cases). Этот слой полностью независим от специфичных для Android фреймворков.
* Слой данных (Data Layer): Реализует интерфейсы репозиториев, определенных в слое предметной области. Обрабатывает операции получения, кэширования и хранения данных через сетевые запросы и локальную базу данных.
* Слой представления (Presentation Layer): Управляет пользовательским интерфейсом и состоянием. ViewModels обрабатывают намерения пользователя (подход, близкий к MVI) и предоставляют реактивные состояния (StateFlow) для UI-компонентов.

## Технологический стек
Проект построен с использованием следующих технологий и библиотек:

### Основной стек и язык
* Kotlin
* Kotlin Coroutines для асинхронного программирования
* Kotlin Flow / StateFlow для реактивного управления состоянием

### Пользовательский интерфейс
* Jetpack Compose для декларативного построения UI
* Material 3 (дизайн-система)
* Jetpack Navigation Compose для маршрутизации и навигации между экранами
* Coil для асинхронной загрузки изображений

### Внедрение зависимостей
* Dagger Hilt

### Сеть и API
* Retrofit для взаимодействия с REST API
* OkHttp3 (включая Logging Interceptor)
* Kotlinx Serialization для парсинга и маппинга JSON

### Локальное хранение данных и фоновые задачи
* Room Database для локального кэширования и работы в офлайн-режиме
* DataStore для управления настройками пользователя
* AndroidX Security Crypto (EncryptedSharedPreferences) для безопасного хранения токенов аутентификации
* WorkManager для фоновых задач синхронизации данных

### Тестирование
* JUnit 4 для базового модульного (unit) тестирования
* MockK для создания мок-объектов
* Turbine для тестирования Kotlin Flows
* Kotlinx Coroutines Test для контроля выполнения корутин в тестах
* Compose UI Test framework для инструментального тестирования пользовательского интерфейса
* Room Testing для проверки логики работы локальной базы данных

## Система сборки
* Gradle с использованием Kotlin DSL (.gradle.kts)
* Version Catalogs (libs.versions.toml) для управления зависимостями

## Основной функционал
* Аутентификация пользователей с безопасным хранением учетных данных.
* Просмотр фильмов с сортировкой по популярности или высоким рейтингам с поддержкой пагинации.
* Просмотр подробной информации о фильме, включая жанры, продолжительность и описание.
* Добавление и удаление фильмов из личного списка избранного.
* Синхронизация списка избранных фильмов между локальной базой данных и удаленным сервером.
* Управление настройками приложения, включая динамический выбор языка интерфейса.
